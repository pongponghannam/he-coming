# 그가 온다 — 1인칭 추격 공포게임

업로드된 사진을 추격자 캐릭터로 사용하는 순수 HTML/CSS/JavaScript 게임입니다.

## 바로 실행하기
- `index.html`을 Chrome, Safari, Edge 등에서 열고 **게임 시작**을 누릅니다.
- 이미지와 효과음 코드는 `index.html` 안에 포함되어 있어 다른 파일이나 인터넷 연결이 필요하지 않습니다.

## 게임 목표
- 미로에서 기억 조각 3개를 수집하고 출구로 이동합니다.
- 추격자에게 닿으면 게임 오버입니다.
- 체력을 관리하며 달리세요. 화면의 방향 안내와 지도(M)를 활용할 수 있습니다.

## 조작
- PC: WASD 이동, 마우스 드래그 또는 방향키로 시야 회전, Shift 달리기, M 지도, P 일시정지
- 스마트폰/태블릿: 왼쪽 조이스틱 이동, 오른쪽 화면 드래그 시야 회전, 달리기 버튼 길게 누르기

## GitHub Pages에 게시하기
1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 최상위 경로에 업로드합니다.
3. 저장소 **Settings → Pages**에서 **Deploy from a branch**, 브랜치 **main**, 폴더 **/(root)**를 선택하고 저장합니다.
4. GitHub Pages 배포가 완료되면 제공된 URL로 접속할 수 있습니다.

## 기술
- Canvas 2D 기반 1인칭 레이캐스팅(별도 라이브러리 불필요)
- 미로 생성 및 추격자 경로 탐색, 모바일 터치 조작
- Web Audio API를 이용한 합성 효과음(외부 음원 없음)
